# dados-atletas

O projeto 2 da trilha 1 dados dos atletas eh feitos principalmente com uma classe Atleta que eh instaciada 4 vezes recebendo parametros como nome, idade, peso, altura e 5 notas em forma de matriz. Na matriz são criadas as variáveis de instância e depois são feitos os métodos solicitados como imc, média e categoria e também são obtidos os valores de nome, idade, peso e altura e já no final da classe é feito o método de saída do código conforme solicitado. E assim é chamado o metodo saída 4 vezes para mostrar a sáida do código.
